# Fake Cookie Generator

Fake Cookie Generator creates realistic-looking **fake Roblox `.ROBLOSECURITY` cookies** for demonstrations, testing, and educational purposes. Every cookie is randomly generated and **does not belong to a real Roblox account**.

This tool can be useful for showing how cookie scams work, creating cybersecurity demonstrations, or sending harmless fake cookies to scammers who ask for your real one. None of the generated cookies can be be used to log into Roblox or access anyone's account.

## Features

- Instantly generates random fake Roblox cookies.
- One-click copy to clipboard.
- Every generated cookie is completely fake.
- No generated cookie can authenticate or access a Roblox account.
- Lightweight and easy to use.
